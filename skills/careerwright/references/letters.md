# Cover letters

Load when writing or reviewing a cover letter.

- Hiring-manager surveys (Resume Genius, ResumeLab and similar, vendor-run, so soft evidence) agree on one thing: a tailored letter helps and a generic one hurts. Write one only when it can be specific.
- Shape: greeting to a named person when the posting or team page gives one, else "Hello <team> team". Paragraph 1: the role and one checked fact about the company that made the person want it. Paragraph 2: two pieces of the person's real work that match the posting's top two needs, each with a number. Paragraph 3: one line on what they want to do next there, and a plain close.
- Under 300 words. No opening "I am writing to express", no "passionate", no restating the resume line by line.
- Use the posting's terms only where true. Never invent a metric; ask the person for the number or leave it out.
- Save as markdown; convert to PDF or DOCX only if the application form wants a file.
